# Fern & Flow — Kerala Homestay Website Prototype

A responsive static website concept for a Kerala homestay with 6–10 rooms.

## Included
- Responsive landing page, story, rooms, experiences and gallery sections
- Booking enquiry form with date validation
- WhatsApp enquiry handoff
- Demo admin dashboard for viewing enquiries and sample room catalogue
- Browser-local enquiry storage using localStorage

## Preview admin access
- URL: `/#admin`
- Email: `admin@fernflow.demo`
- Password: `stay123`

## Important prototype limitations
This is a front-end demo, not a production booking system. Enquiries are stored only in the current browser/device. There is no shared database, secure authentication, live room availability, online payment, automated confirmation, or email notification. The WhatsApp number in `index.html` is a placeholder and must be replaced before launch. Replace sample property details, pricing, room information and imagery with the owner's approved content.

## Run locally
Open `index.html` in a browser, or serve the repository with any static web server.

## Deploy
Suitable for Vercel static hosting. No build step is required.
